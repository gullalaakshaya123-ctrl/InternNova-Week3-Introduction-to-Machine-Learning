# InternNova Week 3 – Introduction to Machine Learning

## Internship
**InternNova AI/ML Internship – Week 3**

## Overview
This project covers the fundamentals of Machine Learning, dataset preparation, preprocessing, model training, evaluation, and student performance prediction using Python.

## Tasks Completed

### Task 1 – ML Fundamentals
- Introduction to Machine Learning
- AI vs ML vs Deep Learning
- Supervised and Unsupervised Learning
- Classification and Regression
- ML applications

### Task 2 – Dataset Preparation
- Loaded dataset using Pandas
- Inspected dataset shape and columns
- Checked missing values
- Separated features and target

### Task 3 – Train-Test Split & Preprocessing
- Split dataset into training and testing sets
- Encoded categorical labels using LabelEncoder
- Standardized features using StandardScaler

### Task 4 – First Machine Learning Model
- Built a Decision Tree Classifier
- Trained the model
- Generated predictions
- Evaluated model performance

### Task 5 – Mini Project
**Student Performance Prediction**

- Used student academic data
- Implemented a Decision Tree Classification model
- Predicted Pass/Fail results
- Tested predictions for new student records
